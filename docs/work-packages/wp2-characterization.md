# WP2 · Empirical Characterization

**Objective:** Observe forensic-readiness-relevant properties within actual software engineering artifacts, especially those exposed through repositories and change histories.

## Primary study

[FRSE-S02: Mining Software Repositories for Forensic Readiness](../studies/s02-repository-mining/)

## Candidate activity sequence

1. Operationalize FREM constructs as observable evidence candidates.
2. Define repository inclusion, sampling, and ethical collection rules.
3. Extract and classify engineering artifacts and change histories.
4. Analyze correspondence between observed changes and readiness-related evidence properties.
5. Evaluate the reliability and limits of the mapping from concepts to observations.

Activities are provisional until documented in the final study protocol.
