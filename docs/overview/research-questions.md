# Research Questions

The program-level questions below summarize the scope of FRSE; **they are not replacements for the formally defined RQs in individual study protocols**.

| Code | Program-level question |
| --- | --- |
| FRSE-RQ1 | What concepts, evidence requirements, engineering artifacts and practices characterize forensic readiness in software systems? |
| FRSE-RQ2 | How do repositories, changes, and development workflows preserve or undermine software forensic readiness? |
| FRSE-RQ3 | How can forensic readiness be assessed and measured using theoretically and empirically grounded indicators? |
| FRSE-RQ4 | To what extent can readiness-related conditions be predicted from software evolution data? |
| FRSE-RQ5 | Which improvement practices can address evidence gaps, and how can they be evaluated? |

Research Questions FRSE-RQ3 to FRSE-RQ5 represent **program directions** rather than claims of approved or completed protocols.

## Study-specific research questions

- **[S01](../studies/s01-multivocal-review/)** addresses forensic-readiness concepts and definitions, evidence types, software artifacts and practices, and assessment dimensions.
- **[S01-TAX](../studies/s01-taxonomy/)** investigates how identified constructs can be classified and evaluated.
- **[S01-ONT](../studies/s01-ontology/)** is reserved for future questions about machine-interpretable knowledge representation.
- **[S02](../studies/s02-repository-mining/)** will formalize repository-mining RQs in its approved protocol before empirical results are reported.
