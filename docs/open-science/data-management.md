# Data Management and Release Policy

FRSE publishes only research material cleared for public distribution.

## Release procedure

| Stage | Requirements |
| --- | --- |
| Internal working data | Maintain controlled access and provenance |
| Release candidate | Remove sensitive material; review licenses, ethics and provenance |
| Approved package | Add a frozen version, metadata, citation and reproducibility instructions |
| Public release | Publish archive or repository tag; link DOI if available |
| Revision | Record changes; retain links to previous released versions |

## Third-party material

Academic articles, proprietary datasets and copyrighted PDFs must not be redistributed simply because they were used in a systematic review. Provide references and extraction metadata where redistribution is permitted.

## Manuscripts

Submitted manuscripts and double-blind review materials are not automatically public. Preprints, accepted manuscripts and final versions will be posted only where author and publisher policies allow it.

## Licensing

The starter repository intentionally does not assert a reuse license for future research datasets or code. Review [License policy](https://github.com/edson-ao-junior/frse/blob/main/LICENSE-POLICY.md) before public release. Specific packages may adopt different licenses.
