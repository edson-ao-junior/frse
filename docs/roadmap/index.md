## How work is tracked

- **Work package** identifies the strategic research stream.
- **Study ID** associates tasks with a scientific protocol.
- **Issue / milestone** represents an actionable activity or deliverable.
- **Publication record** tracks manuscripts independently of scientific progress.
- **Research output release** records whether data, protocols, models and tools are actually public.

## Recommended GitHub Project views

**Research Board:** Backlog · Planned · In progress · In review · Done · Blocked.

**Deliverables:** grouped by type (paper, model, dataset, protocol, tool) and filtered by release readiness.

**Timeline:** start and target dates, milestone dependencies and owners.
