# Datasets and Tools

No dataset or executable software package is represented as publicly released in the initial FRSE repository.

This page is reserved for verified research packages with appropriate licenses, provenance and documentation.

## Release checklist

- [ ] Release identifier and version.
- [ ] Description, creator, study and related research questions.
- [ ] Data collection and processing procedure.
- [ ] Data dictionary, file inventory and integrity checksums.
- [ ] Ethics, privacy, copyright and redistribution review.
- [ ] Reproduction instructions and software environment.
- [ ] DOI and citation instructions where applicable.

The page will provide working links only after the corresponding packages are released.
