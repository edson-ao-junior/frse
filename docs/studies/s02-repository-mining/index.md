# FRSE-S02 · Mining Software Repositories

**Working title:** Mining Software Repositories for Forensic Readiness  
**Research status:** Study preparation and initial methodological development.  
**WP:** [WP2](../../work-packages/wp2-characterization.md)

## Objective

Investigate whether software changes and engineering artifacts in real repositories provide evidence of forensic-readiness-related practices and properties.

## Planned methodological activities

1. Translate relevant FREM concepts into observable repository signals, while recording unobservable constructs.
2. Define sampling and inclusion/exclusion criteria for repositories.
3. Design and pilot the data collection and extraction instruments.
4. Analyze commits, issue discussions, code changes, configuration changes and other eligible artifacts.
5. Assess how observations support, contradict or fail to address readiness-related properties.
6. Document threats to validity and prepare a replicable research package.

## Scientific care

A change mentioning logging or auditability does not automatically demonstrate actual forensic readiness. Mapping repository observations to concepts requires operational definitions, corroborating evidence, and attention to missing context.

Study-specific RQs, sample sizes and outcomes will be published after they are finalized; no numerical results are asserted at this stage.
