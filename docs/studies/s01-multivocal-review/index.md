# FRSE-S01 · Multivocal Review and FREM

**Title:** Evidence-Based Foundations of Forensic Readiness in Software Engineering

**Research status:** Multivocal synthesis completed; model documentation and scientific manuscript in preparation.  
**Artifacts:** Working materials exist internally. Public release packages have not yet been attached to this repository.  
**WP:** [WP1](../../work-packages/wp1-foundations.md)

## Objective

Investigate the concepts, evidence requirements and software engineering practices that characterize forensic readiness, and develop an evidence-based conceptual model for software systems.

## Research questions

1. Which forensic-readiness concepts and definitions are reported in the literature?
2. Which evidence types and properties are considered relevant?
3. Which software artifacts and engineering practices support readiness?
4. Which dimensions can inform forensic-readiness assessment?

## Methods and evidence

The study combines a **Systematic Mapping Study (SMS)** with a **Grey Literature Review (GLR)** and performs integration at concept level, preserving the provenance and type of each evidence claim.

| Evidence component | Recorded outcome |
| --- | ---: |
| Academic studies included | 99 |
| Accepted grey-literature sources | 54 |
| Grey-literature source-level claims | 1,054 |
| Canonical concepts in grey-literature analysis | 312 |
| Harmonized core forensic-readiness constructs | 20 |

The counts above reflect distinct analytical stages; they are not interchangeable with the number of final model elements.

- Evidence-derived FREM conceptual model and derivation trace.
