# FRSE | Forensic Readiness Software Engineering

**Evidence-based research on forensic readiness across the software lifecycle.**

FRSE is an open research program focused on understanding, characterizing, assessing, predicting, and improving forensic readiness in evolving software systems.

🌐 **Research website (after initial deployment):** https://edson-ao-junior.github.io/frse/  
📂 **Repository:** https://github.com/edson-ao-junior/frse  
📘 **Deployment steps in Portuguese:** [COMO_PUBLICAR_PT.md](COMO_PUBLICAR_PT.md)

## Research streams

| Stream | Focus |
| --- | --- |
| WP1 | Evidence synthesis, FREM conceptual model, taxonomy and ontology |
| WP2 | Empirical characterization through software repository mining |
| WP3 | Assessment methods, metrics, and predictive analyses |
| WP4 | Evidence gap analysis, improvement approaches and independent evaluation |

## Current research snapshot

- **FRSE-S01**: Multivocal synthesis performed using 99 academic studies and 54 accepted grey-literature sources; the model and paper package are being prepared for public release.
- **FRSE-S01-TAX**: Taxonomy under development; independent evaluation is not yet reported.
- **FRSE-S01-ONT**: Ontology planned.
- **FRSE-S02**: Repository-mining study in preparation.
- Other research directions are provisional and will be refined through future protocols.

**As of:** 17 October 2026. The status board distinguishes research progress from public artifact release and publication status.

## Getting started

1. Open [COMO_PUBLICAR_PT.md](COMO_PUBLICAR_PT.md).
2. Publish the repository using GitHub Desktop (repository name **frse**).
3. In GitHub, set **Settings → Pages → Source → GitHub Actions**.
4. From then on, changes pushed to `main` publish the site automatically.

To edit study statuses, update [`metadata/studies.json`](metadata/studies.json). For publication records, update [`metadata/publications.json`](metadata/publications.json). The workflow regenerates the public catalogs automatically.
