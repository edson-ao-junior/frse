# Licensing and reuse policy

No license has been selected for this initial website and repository template. As a result, public visibility does **not** by itself grant reuse rights.

Before publishing reusable protocols, code, datasets or model packages, the maintainers should choose and include appropriate explicit licenses (for example, a code license and a separate documentation/data license), verify rights in third-party content, and record any embargoes or ethical restrictions.

Please cite linked scholarly papers or versioned research outputs as directed in `CITATION.cff` and on their release pages.
